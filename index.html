归并排序的分治思想

1. 原理

  1. 思考一个问题在大范围上的答案，是否等于，左部分的答案 + 右部分的答案 + 跨越左右产生的答案
  2. 计算“跨越左右产生的答案”时，如果加上左、右各自有序这个设定，会不会获得计算的便利性
  3. 如果以上两点都成立，那么该问题很可能被归并分治解决
  4. 求解答案的过程中只需要加入归并排序的过程即可，因为要让左、右各自有序，来获得计算的便利性

每日算法---归并排序

归并排序(Merge sort)

1. 简介

摘自维基百科
归并排序（英语：Merge sort，或mergesort），是建立在归并操作上的一种有效的排序算法，效率为
O(nlogn)。1945年由约翰·冯·诺伊曼首次提出。该算法是采用分治法（Divide and Conquer）的一个非常典型的应用，且各层分治递归可以同时进行。

2. 我的理解

归并排序通过分而治之的办法实现了排序比较的利用最大化,实现时间复杂度上的高性能和稳定性,但是由于需要辅助数组,所以空间复杂度偏高.整体思路为,通过对于一个数组进行多次分割,然后排序,合并起来实现对于一个数据的排序.常规算法实现有两种方法,递归和非递归,下面将依次用C++实现

4. 总结

对于两种归并排序如何使用主要看数据数量,递归实现虽然实现更为简单,但是递归本质是调用了系统栈,要是数据过大容易有爆栈风险,如果数据量大,最好还是选择非递归实现

如何把vim配置的和vscode一样好用

在 Ubuntu 24.04 上把 Vim 配成像 VS Code 一样好用：C/C++ 完整指南

Vim 刚装好时很轻便，但缺少现代 IDE 常见的代码补全、错误诊断、跳转和项目搜索。好消息是，我们可以通过插件和语言服务器，把这些开发体验接进 Vim。

本文以 Ubuntu 24.04 + 原版 Vim + C/C++ 为例，逐步安装并配置：

  • 代码补全：输入代码时显示类型、函数和成员建议。
  • 语义诊断：在编辑时发现类型错误、头文件或编译参数问题。
  • 代码导航：跳转到定义、查找引用、查看说明和重命名。
  • 项目工具：文件树、模糊搜索、Git 操作和代码格式化。

文中所说的“像 VS Code 一样”指常用编辑与语言服务体验接近，不代表完整复刻 VS Code 的图形界面、调试器和所有扩展。不同编程语言要接入各自的语言服务器；本文配置的是 C/C++。

先看整体流程

  1. 安装 Vim、编译工具、CMake、clangd 和项目依赖。
  2. 准备符合 Coc 要求的 Node.js。
  3. 用 vim-plug 安装和管理 Vim 插件。
  4. 配置 Coc 与 C/C++ 语言服务器 clangd。
  5. 给 clangd 提供项目真实的编译参数。
  6. 在 Vim 里验证补全、跳转、诊断和格式化。
