每日算法---位图

位图

1. 简介

摘自维基百科
位图可指一种数据结构，代表了有限域中的稠集（dense set），每一个元素至少出现一次，没有其他的数据和元素相关联。该结构在索引、数据压缩等方面有广泛应用。

2. 我的理解

也是一种统计用的数据结构,如果对于一个范围内的数组,统计哪些数字出现过,一半可能会用哈希表或者数组来统计,但是位图能做到比哈希表和数组更少的空间实现数据记录.实现原理为,对于一个32位int类型,需要占32位的bit位,所以每一个比特位就可以用来表示对应的数字是否被统计.

4. 总结

作为一种统计数据结构,在小范围统计里面,无疑是比哈希表和数组更加省空间的,而且实现很简单,对于空间比较拮据的情况,是可以考虑的.
