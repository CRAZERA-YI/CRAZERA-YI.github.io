每日算法---归并排序(拓)

归并排序的分治思想

1. 原理

  1. 思考一个问题在大范围上的答案，是否等于，左部分的答案 + 右部分的答案 + 跨越左右产生的答案
  2. 计算“跨越左右产生的答案”时，如果加上左、右各自有序这个设定，会不会获得计算的便利性
  3. 如果以上两点都成立，那么该问题很可能被归并分治解决
  4. 求解答案的过程中只需要加入归并排序的过程即可，因为要让左、右各自有序，来获得计算的便利性

3. 解法

3.1 一般思路

直接暴力遍历每一个数字,与前面的数字进行比较,时间复杂度会到O(n^2),对于这个复杂度实在不是很合适

3.2 归并分治

思考

思考 : 此题目是否满足归并分治的原理

思考 : 对于一个任意位置的数字,他的小和大小与前面的数字的顺序无关,故是否可以通过使得前面有序来简化计算

通过思考,我们发现此题目符合上面两个要去,故可以考虑使用归并分治来实现小和问题的低时间复杂度实现

代码构思
