每日算法---桶排序与基数排序

桶排序(Bucket Sort)

1. 简介

摘自维基百科
桶排序（英语：Bucket sort）或所谓的箱排序，是一个排序算法，工作的原理是将数组分到有限数量的桶里。每个桶再个别排序（有可能再使用别的排序算法或是以递归方式继续使用桶排序进行排序）。桶排序是鸽巢排序的一般化(generalization)。当要被排序的数组内的数值是均匀分配的时候，桶排序使用线性时间（O(n)）。

桶排序以下列程序进行：

  1. 设置一个定量的数组当作空桶子。
  2. 寻访序列，并且把项目一个一个放到对应的桶子去。
  3. 对每个不是空的桶子进行排序。
  4. 从不是空的桶子里把项目再放回原来的序列中。

2. 我的理解

桶排序是非交换排序,利用最简单粗暴的统计法,完成排序,虽然比较快,但要是面对大数量级的数字的时候,就不太合适了.实现很简单,所以代码就不写了

基数排序(Radix Sort)

1. 简介

摘自维基百科
基数排序（英语：Radix sort）是一种非比较型整数排序算法，其原理是将整数按位数切割成不同的数字，然后按每个位数分别比较。由于整数也可以表达字符串（比如名字或日期）和特定格式的浮点数，所以基数排序也不是只能使用于整数。

它是这样实现的：将所有待比较数值（正整数）统一为同样的数位长度，数位较短的数前面补零。然后，从最低位开始，依次进行一次排序。这样从最低位排序一直到最高位排序完成以后，数列就变成一个有序序列。

基数排序的方式可以采用LSD（Least significant digital）或MSD（Most significant digital），LSD的排序方式由键值的最右边开始，而MSD则相反，由键值的最左边开始。
老资历
基数排序的发明可以追溯到1887年赫尔曼·何乐礼在打孔卡片制表机上的贡献。基数排序算法早在1923年被广泛运用在打孔卡的排序。

2. 我的理解

基数排序和桶排序相比于其他排序很特殊,基数排序属于是桶排序的进阶版,他并不是依赖交换进行排序,而且通过每个数位计数进行排序,所以对于低数量级的数,可以做到很快的速度

3. 代码实现

基础版

仅限制正数数组排序,如果需要实现负数表示,只需要把最小值找出来,然后数组里面的数字减去最小值,最后再分别加上最小值就可以了,下面展示的版本是最简单的,就不添加这个了,以及最大位数也可以通过函数内部实现,下面也是不实现了,直接通过传参获取

进阶版

也是仅限正数排序,支持N进制调整,不需要一个个遍历桶了

4. 总结

作为为数不多不用交换的数组,实现原理还是很有趣,思路很值得的学习
