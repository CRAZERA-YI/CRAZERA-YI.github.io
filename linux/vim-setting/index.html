如何把vim配置的和vscode一样好用

在 Ubuntu 24.04 上把 Vim 配成像 VS Code 一样好用：C/C++ 完整指南

Vim 刚装好时很轻便，但缺少现代 IDE 常见的代码补全、错误诊断、跳转和项目搜索。好消息是，我们可以通过插件和语言服务器，把这些开发体验接进 Vim。

本文以 Ubuntu 24.04 + 原版 Vim + C/C++ 为例，逐步安装并配置：

  • 代码补全：输入代码时显示类型、函数和成员建议。
  • 语义诊断：在编辑时发现类型错误、头文件或编译参数问题。
  • 代码导航：跳转到定义、查找引用、查看说明和重命名。
  • 项目工具：文件树、模糊搜索、Git 操作和代码格式化。

文中所说的“像 VS Code 一样”指常用编辑与语言服务体验接近，不代表完整复刻 VS Code 的图形界面、调试器和所有扩展。不同编程语言要接入各自的语言服务器；本文配置的是 C/C++。

先看整体流程

  1. 安装 Vim、编译工具、CMake、clangd 和项目依赖。
  2. 准备符合 Coc 要求的 Node.js。
  3. 用 vim-plug 安装和管理 Vim 插件。
  4. 配置 Coc 与 C/C++ 语言服务器 clangd。
  5. 给 clangd 提供项目真实的编译参数。
  6. 在 Vim 里验证补全、跳转、诊断和格式化。

功能 操作 作用
自动补全 在插入模式输入代码 由 Coc 扩展和 clangd 提供候选项。

查看说明 普通模式按 K 显示符号类型或文档说明。
重命名 先按空格，再依次按 r、n 按语义重命名变量、函数等符号。
格式化 先按空格，再按 f 请求 clangd 格式化当前文件；项目规则可由 .clang-format 控制。
上一个 / 下一个诊断 普通模式按 [d / ]d 在错误与警告之间移动。

搜索文件 按 Ctrl+p 在项目文件中模糊查找。
搜索项目内容 先按空格，再按 s 通过 ripgrep 搜索文本。
查看 Git 状态 运行 :Git 使用 Fugitive 查看和操作仓库。

这里空格是配置里的 <leader> 键，所以 空格 → r → n 是依次按三个键，不是同时按住。
