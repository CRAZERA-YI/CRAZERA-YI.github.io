实用网站分享

一. 代码托管平台

目前主流的都是基于git做的平台,至于git是什么,简单科普一下
git
git 是一个分布式版本控制软件，最初由林纳斯·托瓦兹创作，于2005年以GPL许可协议发布。最初目的是为了更好地管理Linux内核开发而设计。应注意的是，这与GNU Interactive Tools（一个类似Norton Commander界面的文件管理器）不同。

git最初的开发动力来自于BitKeeper和Monotone。git最初只是作为一个可以被其他前端（比如Cogito或Stgit）包装的后端而开发的，但后来git内核已经成熟到可以独立地用作版本控制。很多被广泛使用的软件项目都使用 git 进行版本控制，其中包括 Linux 内核、X.Org服务器和OLPC内核等项目的开发流程。’

很牛逼的事情是,git的创始人和Linux的创始人是同一个

1. Github

首当其冲的就是大名鼎鼎的Github,目前是归微软所有,使用人数来说应该是最多的,资源也特别丰富,就是有时候会有网络问题,国内无法正常访问
https://github.com/

2. Gitee

以及国内版的Github,Gitee(码云),好处的不用翻墙,但是很多功能受限制,而且代码居然要审核,也是神了
https://gitee.com/

二. 电子书资源平台

1. Z-Library

俄罗斯臭名昭著(大名鼎鼎)的盗版书网站,资源很丰富,而且下载速度也不错,唯一的缺点可能就是网站容易被制裁或者某些书受到版权限制
https://zh.z-lib.sk/

2. Anna’s Archive

这个算是一个聚合站,包含了zlib的资源,而且可以国内访问,缺点就是没开会员下载特别慢
https://annas-archive.gl/

三. 算法刷题

1. 洛谷

ACM类刷题平台,资源丰富平台体量大用户多
https://www.luogu.com.cn/

2. Leecode

力扣也是一个很大的算法平台,而且用户,题库都很多,偏向于求职者,答题模式为类模式
https://leetcode.cn/

3. 牛客

也是一个偏向于求职者的刷题平台
https://www.nowcoder.com/

四. 学习网站

1. 菜鸟教程

老牌的计算机教程网站,很多技术的教程这里面都有,但是不算是特别优秀,甚至有些新点的技术我感觉还是AI写的,拿来当个科普读物还行
https://www.runoob.com/

2. BiliBili

https://www.bilibili.com/
B站上面资源真的很丰富,很多技术教程都能在B站找到,当然有免费也有付费的,按需购买吧,我自认为很多技术免费课程都已经足够了

3. 很多B站up主的博客

我资历有限,我只能推荐几个我觉得还不错的up主了

恋恋风尘(C++/Python技术)

这个博主的教程偏向于工程应用,适合进阶
博主的B站主页 : https://space.bilibili.com/271469206?spm_id_from=333.1387.follow.user_card.click

博主的博客 : https://llfc.club/

爱编程的大丙(啥都会,很牛逼)

这个博主讲的很仔细通俗,基本上都是入门教程视频,很适合初学者学习
博主的B站主页 : https://space.bilibili.com/147020887?spm_id_from=333.1387.follow.user_card.click

博主的博客 : https://subingwen.cn/

程序员鱼皮

这个博主偏向于杂谈科普类的吧,但是他的GitHub上面的资料还是很丰富,值得看看有咩有自己需要的
博主的B站主页 : https://space.bilibili.com/12890453?spm_id_from=333.337.0.0
博主的博客 : https://codefather.cn
博主的Github主页 : https://github.com/liyupi/codefather

若干的机构博主

很多机构都是会放一些免费课程出来让你试听的,所有他们的课也是可以学学的,但是深入学习一般就需要付费了
