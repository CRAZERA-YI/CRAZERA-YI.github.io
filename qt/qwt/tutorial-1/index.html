Qwt教程(一):Qwt环境搭建

概览、核心理念与环境搭建

引言

Qwt（Qt Widgets for Technical Applications）是一套面向科学计算与工程技术的开源 Qt 控件库，最早由 Josef Wilgen 于 1997 年创建，自 2002 年起由 Uwe Rathmann 长期维护，目前稳定版本为 6.3.0（自 Qwt 6 起放弃 Qt3，并进行了较大的 API 演进）。

和很多“开箱即用但改不动”的图表库不同，Qwt 的核心组件 QwtPlot 主打极高的灵活性与大数据渲染性能——它本质上是给 C++/Qt 工程师准备的底层绘图框架。在敲下第一行代码前，必须先吃透它的三大核心设计理念。

1. Qwt 的三大核心设计理念（全书总纲）

1.1 所有权机制（Ownership Concept）

这是写 Qwt 代码**最容易触发崩溃（野指针 / double free）**的地方：

  • QwtPlot 接管所有添加给它的元素的所有权（曲线、网格、标记线、图例、坐标轴引擎等，概莫能外）。
  • 因此，所有图元必须用 new 在堆上创建，再交给 QwtPlot；之后绝对不要自己 delete，也绝对不要在栈上创建图元（否则析构顺序稍有不对就会触发内存访问冲突）。
  • 已添加到 QwtPlot 的元素一般不再“摘下来复用”（除 QwtPlotItem::detach() 外，像图例这类对象甚至没有简单的 release() 接口）。遇到需要动态重建的图表元素，书里推荐采用**工厂模式（Factory Concept）**按需重新创建。

1.2 图元与坐标轴的强绑定（Axis Dependency）

  • QwtPlot 允许往画布里塞入任意绘图元素（QwtPlotItem 子类：曲线、柱状图、热力图、标记线、网格……）。
  • 为了让图元随缩放、范围变化自动重算屏幕位置，每个图元都必须绑定坐标轴，从而在坐标轴刻度变化时收到通知。
  • 也正因为坐标轴是整个坐标变换的枢纽，QwtPlot 内置固定了最多 4 条坐标轴（左 Y、右 Y、底 X、顶 X），它们是牢牢锚定在 QwtPlot 上的，不像曲线那样可以随意增删。

1.3 彻底的多态扩展（Inheritance Concept）

  • Qwt 的类体系几乎处处支持多态（虚函数）。
  • 如果内置功能差一口气（例如：给柱状图每个柱子单独上色、把 X 轴数字换成文字、自定义图例图标、给渲染函数打耗时统计），标准做法不是魔改库源码，而是继承对应类并重写目标虚函数。

2. 编译、安装与集成 Qwt 6.3.0

2.1 获取与安装方式

平台 推荐方式 说明
Windows / macOS 源码编译（推荐） 下载 qwt-6.3.0.zip（SourceForge）自行编译，过程很简单，且能严格匹配你本机的 Qt 与编译器 ABI
Linux (Debian/Ubuntu) 包管理器或源码 开发包：sudo apt install libqwt-qt5-dev（头文件在 /usr/include/qwt）；运行部署只需 libqwt-qt5-6

2.3 在 Qt Designer / .ui 文件中嵌入 QwtPlot

避坑警告（原书 1.6 节）：虽然 Qwt 自带 Qt Designer 插件，但由于新版 Qt Creator 修改了 Designer 插件 API，Qwt 的 Designer 插件在较新版本的 Qt / Qt Creator 上往往无法加载（哪怕你用同一套工具链自己编的也不行）；而且即使能加载，也不能在 Designer 里配置曲线，真正配置全都在 C++ 代码里完成。

因此，实战中最稳妥、最通用的做法是“占位符提升（Promote to…）”：

  1. 在 Qt Designer 界面里直接拖一个普通的 QWidget 到布局中。
  2. 右键该 QWidget → 选择 Promote to…（提升为…）。
  3. 填写提升信息：
    • Base class name（基类）：QWidget
    • Promoted class name（提升的类名）：QwtPlot
    • Header file（头文件）：QwtPlot（如果兼容旧版 Qwt 或 Linux 发行版包，填 qwt_plot.h）
    • 勾选 Global include（全局包含） → 点击 Add → 点击 Promote。
  4. 把控件 objectName 改为 plot，放进垂直布局（QVBoxLayout）时，若希望图表吃满剩余空间，把顶层布局的 layoutStretch 设为类似 0,1（上方工具栏 0，下方图表 1）。

3. 除了 QwtPlot，Qwt 还提供哪些仪表/输入控件？（原书 Ch 3）

Qwt 不仅仅是画图库，它还自带一套模仿经典科学/工业仪器面板的输入与显示控件。它们底层复用了第 11 章的刻度计算与绘制引擎，支持非线性刻度（如对数刻度）与高度自定义配色，弥补了原生 Qt 控件在工业仪表场景下的不足。

Qwt 控件类 对应的原生 Qt 控件 Qwt 的核心优势
QwtSlider QSlider 支持鼠标/方向键操作，刻度定义远比 QSlider 灵活，支持非线性刻度
QwtWheel 无 水平或垂直调节滚轮（类似示波器/调音台拨轮）
QwtThermo QProgressBar 温度计/液位柱状显示器；不受平台原生风格限制，自带刻度，支持配置颜色表（渐变或超阈值变色报警）
QwtKnob QDial 工业旋钮，支持丰富的刻度单位与缩放显示
QwtDial 无 模拟指针表盘（可开启鼠标/键盘调节）；指针本身解耦为独立类（默认 QwtDialSimpleNeedle），可完全自定义任意指针样式

上述全部控件的直观效果都收录在 Qwt 源码自带的 examples/controls 示例工程中，编完库之后强烈建议跑一遍看效果。

另外，在 Qt 6 下使用 Qwt 6.3.0 时注意两处小差异：

  • 原书大量使用 QVector<double>，在 Qt 6 中 QVector 已是 QList 的类型别名，可以无缝编译；
  • 宏 QWT_OVERRIDE 是为了兼容古老 C++98 编译器保留的，在现代 C++11 及以上直接写标准关键字 override 更清晰。

本章结论

  • Qwt 是面向工程/科研的 Qt 控件库，QwtPlot 是核心，另有 QwtSlider、QwtWheel、QwtThermo、QwtKnob、QwtDial 等工业仪表控件。
  • 牢记三大铁律：所有图元必须 new 在堆上并由 QwtPlot 接管释放；图元绑定到 4 条固定坐标轴之一；定制行为优先靠继承 + 重写虚函数。
  • Windows/macOS 推荐从源码编译 Qwt 6.3.0，注意 Windows 下 Debug 库名带后缀 d（qwtd），运行时把 lib 目录加入 PATH。
  • 不要死磕 Qt Designer 插件，直接拖一个 QWidget **提升（Promote）**为 QwtPlot 最省心。
