条款15：尽可能使用 constexpr

一句话：constexpr 对象是“编译期已知的 const”，constexpr 函数在实参是编译期常量时给出编译期结果，否则退化成普通运行时函数。能用就用，但要把它当成接口承诺。

1. constexpr 对象

constexpr 对象既是 const，值又在编译期已知：

编译期常量可以用在需要“整数常量表达式”的地方：数组大小、模板实参、枚举值、对齐说明符等。

const 没有这个保证：

一句话：所有 constexpr 对象都是 const，但不是所有 const 对象都是 constexpr。

2. constexpr 函数

constexpr 函数有两种用法：

  • 用编译期常量调用，并且在需要编译期常量的上下文里使用，结果在编译期算出来；
  • 用运行时值调用，它就是普通函数，结果在运行时算出来。

所以不需要写两个版本，一个 constexpr 函数就能兼顾。

4. constexpr 是接口的一部分

constexpr 声明的是：“我可以在需要常量表达式的上下文里使用。”一旦声明，调用方就可能依赖它。

如果以后去掉 constexpr，可能让大量客户代码编译失败。比如你为了调试给函数加了 I/O，而 I/O 通常不允许出现在 constexpr 函数里，这个函数就不再是 constexpr 了。

所以“尽可能使用”还有一层含义：你愿意长期遵守 constexpr 带来的限制。

5. 记住

  • constexpr 对象是 const，并且用编译期已知的值初始化。
  • constexpr 函数在实参是编译期常量时能产生编译期结果；实参是运行时值时，它就是普通函数。
  • constexpr 对象和函数能用在比非 constexpr 更广的上下文里。
  • constexpr 是对象或函数接口的一部分，声明前要确认能长期遵守限制。
