2. 主要用途：返回类型依赖参数

C++11 里，decltype 最常见的用途是写“返回类型取决于参数类型”的函数模板。比如一个带权限检查的 authAndAccess，它返回容器 operator[] 的结果：

这里的 auto 不是类型推导，而是 C++11 的尾置返回类型语法：返回类型写在参数列表后面、-> 之后。好处是返回类型的声明里可以用到参数 c 和 i；如果按传统写法把返回类型放在函数名前面，c 和 i 还没声明，根本用不了。

这样写，authAndAccess 返回的类型就完全等于 c[i] 的类型：对 std::deque<int>、std::vector<int> 通常是 int&，对 std::vector<bool> 则是那个代理对象。

4. 解法：decltype(auto)

这就是上面所说的其他办法了,相比于C++11的写法还是很好用的
C++14 引入了 decltype(auto)：auto 表示“类型要推导”，decltype 表示“用 decltype 的规则推导”。

现在返回类型和 c[i] 完全一致：常见情况返回 T&，c[i] 返回对象时就返回对象。

6. 两个坑：括号和返回值

对“名字”用 decltype，得到声明类型；对“比名字更复杂的左值表达式”用 decltype，得到 T&。

这个区别在 decltype(auto) 做返回类型时非常致命：

f2 不仅返回类型和 f1 不同，它返回的还是局部变量 x 的引用。函数一返回，引用就悬空，这是标准的未定义行为。
其实这个特性很莫名其妙啊,我实在想不到这玩意有啥用……
所以用 decltype(auto) 时，return 语句里多一对括号就可能改变返回类型。

7. 记住

  • decltype 几乎总是原样返回变量或表达式的类型，不剥引用、不剥 const。
  • 对非名字的左值表达式，decltype 报 T&；对名字，报声明类型。
  • C++14 的 decltype(auto) 用 decltype 规则推导；return x; 和 return (x); 可能得到不同的返回类型。
  • 返回类型依赖参数时，C++11 用 -> decltype(...)，C++14 用 decltype(auto)。
