条款10：优先用限定作用域枚举，而不是未限定作用域枚举

enum class 不会把枚举名泄漏到外层作用域，也不会让枚举值偷偷转换成整数；只有需要隐式转成 size_t 访问 tuple 这类少数场景，才考虑未限定作用域枚举。

5. 记住

  • C++98 风格的 enum 现在叫未限定作用域枚举；枚举名会泄漏到外层作用域。
  • enum class 的枚举名只在枚举内部可见，转换成其他类型必须显式 cast。
  • 两种枚举都可以指定底层类型；enum class 默认底层类型是 int，未限定作用域枚举没有默认底层类型。
  • enum class 总能前向声明；未限定作用域枚举只有指定底层类型后才能前向声明。
