python教程(八)---类

类

引言

类是一个特别体现面向对象编程的东西,它很好的体现了封装,继承,多态.这是一个很有用的东西.
假如你是第一次使用面向对象编程语言的初学者,需要理解一个类可能需要花点时间,简单地说就是一个包含拥有相似特征的变量和函数的集合.
用一个老生常谈的话题来说就是,动物类,内部有细胞作为元素(变量),代谢作为方法(函数),然后其他的详细的动物又可以继承动物类,成为他的子类,比如狗类,就可以多一个跑函数,这就是继承,但是你是不能知道跑是如何运作的,你只能让狗跑,这就是封装,对于多态呢,大概就是不同的动物,虽然都继承自动物类,但是他们进入一个名为跑步的函数的时候,他们跑的方式是不一样的

1. 创建和使用类

几个关键点:

  • 类名首字母大写,这是约定;
  • __init__ 前后各两个下划线,创建实例时自动调用;
  • self 必须放在第一个参数位置,而且不用自己传,Python 会自动把实例传进来,类似 C++ 的 this,但必须显式写;
  • self.name = name 这种带 self. 前缀的变量叫属性,类里所有方法都能访问。
  • python里面没有类似C++/Java里面的private,protected,public权限,但是有一个约定俗成的写法,变量分别这样写name,_name,__name,第三个在程序运行的时候会自动被更名为_类的名字_name
    类定义里的空括号在新版本里可以省略,直接写 class Dog: 也行。

6. 类编码风格

  • 类名用驼峰命名法:ElectricCar,不是 electric_car;
  • 实例名和模块名用小写加下划线:my_tesla、electric_car.py;
  • 每个类定义后面紧跟文档字符串,描述类的功能;
  • 类里用一个空行分隔方法,模块里用两个空行分隔类;
  • 导入时先写标准库,空一行,再写自己写的模块。

本章结论

  • 类把属性和方法打包在一起,class 定义,类名首字母大写。
  • __init__ 创建实例时自动调用,第一个参数 self 必须写,指向实例本身。
  • 属性用 self.xxx 定义,访问和调用方法都用句点:obj.attr、obj.method()。
  • 每个实例有自己独立的属性,一个类可以创建任意多个实例。
  • 属性可以给默认值;修改属性可以直接改,也可以通过方法改(能加检查)。
  • 子类用 class Child(Parent) 继承,super().__init__() 初始化父类部分。
  • 子类可以加自己的属性和方法,也可以重写父类方法。
  • 把实例当成属性,可以把大类拆成小类,避免一个类越写越长。
  • 类可以放在模块里导入,导入方式与函数一样,import * 不推荐。
  • 标准库自带大量模块,OrderedDict 只是其中一个;3.7 之后普通字典也有序了。
  • 类名驼峰、实例名小写、写文档字符串,是 Python 类的三条基本格式约定。
  • __str__ 决定 print(实例) 输出什么,调试时很有用。
