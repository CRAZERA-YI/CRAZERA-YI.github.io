本章结论

  • def 定义函数,函数名后必须有括号和冒号,函数体缩进;三引号是文档字符串。
  • 形参是定义里的变量,实参是调用时传的值;位置实参靠顺序,关键字实参靠名字。
  • 有默认值的形参要放在最后;默认值只在定义时求值一次,可变对象要小心。
  • return 把结果交给调用方,没写就返回 None;可以返回数字、字符串、列表、字典。
  • 列表传进函数是引用,函数里改原列表也会变;不想被改就传 [:] 副本。
  • *args 把多余的位置实参打包成元组,**kwargs 把关键字实参打包成字典。
  • 函数放进模块(独立 .py 文件)里用 import 导入,大型项目靠这个组织代码。
  • 函数名和文件名用小写下划线,文档字符串要写,import 放文件开头。
  • 一个函数只做一件事,任务多了就拆成两个。
