2. 条件测试

条件测试就是值为 True 或 False 的表达式,它是每条 if 语句的核心。

大小写

大小写必然是要区分的,因为本质上英文字符就是ASCII码的具象化,本质是比较两个字符的ASCII是否相同,当然要是是其他语言也是同理

字符串比较区分大小写。要忽略大小写就先 lower() 再比,lower() 返回新字符串,car 本身没变。网站检查用户名是否重复,用的就是这个办法:把新用户名转小写,再和所有既有用户名的小写版本比较,这样 John 和 john 就不会同时存在。

检查不相等

!= 表示”不等于”,在排除某个值的时候比 == 更直接。

比较数字

六种运算符:==、!=、<、<=、>、>=。

检查多个条件

  • and:两个都通过才为 True,有一个不通过就是 False。类比C/C++的&&
  • or:至少一个通过就为 True,两个都不通过才为 False。类比C/C++的||

为可读性可以加括号,虽然不是必须的:(age_0 >= 21) and (age_1 >= 21)。

布尔值

布尔表达式就是条件测试的另一种叫法,结果只有 True 和 False,注意首字母大写,不是字符串。前面第 2 章的补充里提过:非 0 的整数都算 True,0 算 False;空列表、空字符串、空字典也都算 False。后面第 4 节的”列表为空”检查就是靠这个。

这种变量很适合记录程序状态。

本章结论

  • 条件测试的结果只有 True / False,一个等号是赋值,两个等号才是比较。
  • 字符串比较区分大小写,需要时用 lower() 统一后再比。
  • and 要求全部成立,or 只要一个成立;in / not in 用于成员检查。
  • else 是兜底,条件能写清就用 elif;范围条件从窄到宽写。
  • 列表名可直接作为条件:非空为真、空为假。python里面没有empty函数
  • 循环 + if 是处理”大多数元素 + 特殊情况”的标准组合,in 常用来对照另一个列表。
