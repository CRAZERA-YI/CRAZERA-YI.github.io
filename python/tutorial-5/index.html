python教程(五)---字典

字典

引言

列表用下标找数据,字典用名字找数据。假如一个外星人有颜色、点数和坐标,用列表存就得记住”第 0 个是颜色、第 1 个是点数”,很容易记错;用字典可以直接写 alien['color'],意思清楚得多。C++ 里类似的东西是 std::map 和 std::unordered_map,其实准确的说是std::unordered_map,因为python的字典底层实现是哈希表

1. 一个简单的字典

简单的说,字典就是键值对,通过一个key来查询一个value,当然键和值的类型不限

花括号表示字典,'color' 是键,'green' 是值,中间用冒号;键值对之间用逗号。访问时写字典名 + 方括号里的键。

本章结论

  • 字典是键—值对的集合,用名字(键)而不是位置(索引)找数据。
  • 定义用花括号,键值对用冒号,对与对之间用逗号;值可以是任何对象。
  • d[k] 访问、d[k] = v 添加或修改、del d[k] 删除,键不存在访问会报 KeyError。
  • 先建空字典再逐个填,是处理用户输入和批量生成数据的常见写法。
  • items() 遍历键值对、keys() 遍历键、values() 遍历值;默认遍历的是键。
  • 键可以排序后遍历(sorted()),值可以去重后遍历(set())。
  • 嵌套让字典能表示”一群对象”和”对象的多重属性”,但层级越少越好。
  • 从 Python 3.7 起字典按插入顺序遍历,书里”顺序不可预测”的说法已经过时。
  • 不确定键是否存在时用 get(),能避免 KeyError。
