python教程(二)---列表

列表

引言

列表类似其他语言里面的数组,但是列表不限制数据类型,什么数据都能放进去

3.1 列表是什么

方括号表示列表，逗号分隔元素。直接 print 出来的是列表的“内部表示”，带方括号和引号——这通常不是给用户看的输出，所以要学会访问单个元素。

列表元素之间可以毫无关系：字母、数字、人名、甚至不同类型混装都行。书里建议用复数名（letters、digits、names）给列表命名，读代码时一眼能看出它是集合。

访问元素

两个要点：

  1. 索引从 0 开始。第一个元素是 [0]，第四个是 [3]。要访问第 n 个，索引写 n-1。
  2. 负索引从尾部数。[-1] 是最后一个，[-2] 是倒数第二个。好处是不用知道列表有多长——列表长度变了，[-1] 依然指向最后一个。

3.3 组织列表

用户的输入顺序、文件里的记录顺序，往往不受你控制；但展示时经常需要按字母、按数字、按时间排。

reverse()：反转，不是排序

它只是把顺序倒过来，不比较大小。而且再调用一次就恢复原样，所以它虽然也是永久修改，却是可逆的。

len()：长度

len() 从 1 开始数，所以确定长度时不会遇到差一错误。书里举的用例都很实际：还剩几个外星人、有多少条数据、网站有多少注册用户。
注意 sort()、reverse() 都返回 None。写成 cars = cars.sort() 会把列表变成 None，这是新手常见事故。要分清是成员函数还是外部函数

本章结论

  • 列表用方括号和逗号定义，有序、可索引、长度可变、元素类型可以不同。
  • 索引从 0 开始，负索引从尾部数，[-1] 是最常用的“最后一个”。
  • 增：append() 追加、insert() 插入；删：del 按位置不留值、pop() 按位置留值、remove() 按值删第一个。
  • 改：lst[i] = 新值，语法和访问元素一致。
  • 排序要分清“永久”与“临时”：sort() 改原列表、返回 None；sorted() 返回新列表。
  • reverse() 是倒序，不是排序；再调一次即可复原。
  • len() 从 1 数，长度不会差一。
  • IndexError 的本质是差一错误；排查时先打印列表或其长度。
