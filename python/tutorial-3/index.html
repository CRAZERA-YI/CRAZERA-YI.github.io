2. 避免缩进错误

C/C++ 用花括号 {} 划分代码块,Python 没有花括号,靠缩进,只有对应的缩进的代码块才是一个作用域,要是作用域搞错会导致代码出错,需要牢记。所以缩进错了不是排版难看,而是直接改变程序逻辑。

5. 元组

列表适合存运行期间会变的数据;如果一组值整个生命周期都不该变,就用元组。不可变的列表叫元组,某种程度上类似 C++ 的 const。

本章结论

  • for 循环让每条语句对每个元素执行一次,循环体靠缩进界定,不缩进的语句只在循环后执行一次。
  • 循环变量用单数、列表用复数,是可读性最高的一类命名。
  • 缩进错误分两种:语法错误会立刻报出来,逻辑错误只会让结果”看起来对”。
  • range() 含头不含尾,list() 把结果转成列表,第三个参数是步长。
  • 列表解析把”建空表 + 循环 + append”压成一行,for 后不加冒号。
  • 切片 [start:stop] 同样含头不含尾,省略边界就是”从头”或”到尾”。
  • 复制列表必须用 [:],直接赋值只是给同一个列表又起了个名字。
  • 元组用于存不该变的数据;元素不可改,但变量可以重新绑定。
  • PEP 8 的核心不是规则本身,而是”代码主要写给人和未来的自己看”。
