文件和异常

引言

文件读取是一个很重要的模块,小点说就是对于普通文件,大点就文件的处理,网络IO.异常处理也是一个很重要的功能,为我们的代码的健壮性提供了有力支持

1. 从文件中读取数据

读取整个文件与 with 关键字

几个关键点:

  • open() 接收文件名,返回一个表示文件的对象,默认以只读模式打开;
  • with 会在代码块执行完毕后自动关闭文件。这类似 C++ 的 RAII,比手动写 open() 和 close() 安全得多——万一中间代码出 bug 抛异常,close() 没执行就会导致文件句柄泄漏或数据损坏;
  • read() 到达文件末尾时会返回一个空字符串,直接 print(contents) 会多出一个空行,用 rstrip() 去掉末尾多余的空白。

文件路径

  • 相对路径: 相对于当前运行程序所在的目录,如 'text_files/filename.txt'。
  • 绝对路径: 从盘符或根目录开始的完整路径,一般先存进变量再传给 open()。

2. 写入文件

调用 open() 时传入第二个参数指定打开模式:

模式 含义 文件不存在时 文件已存在时
'r' 只读(默认) 报 FileNotFoundError 正常读取
'w' 写入 自动创建 直接清空原内容再写
'a' 附加 自动创建 保留原内容,追加到末尾
'r+' 读写 报 FileNotFoundError 可读可写

另外,write() 只能写入字符串,想写数值数据时必须先用 str() 转成字符串。

4. 存储数据 (json)

纯文本文件只适合存字符串,如果直接把 Python 的列表、字典存盘,下次还得自己写解析逻辑。标准库的 json 模块可以把列表、字典等数据结构直接序列化成 JSON 格式存进文件,下次再原样读回内存,而且 JSON 是跨语言通用的,json太好用了,你几乎可以在所有程序里面看到他,所以学习一下json文件语法还是很有用的

核心就两个函数:

  • json.dump(data, file_obj): 把数据写入文件;
  • json.load(file_obj): 从文件读取并还原为 Python数据结构。
