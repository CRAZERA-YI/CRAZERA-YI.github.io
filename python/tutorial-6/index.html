本章结论

  • input() 的参数是提示,返回值永远是字符串;当数字用要先 int() 或 float()。
  • 提示要清楚,长提示可以先拼好存进变量再传给 input()。
  • % 取余,余数为 0 说明能整除,常用来判断奇偶。
  • while 是”条件成立就一直跑”,for 是”对集合里每个元素跑一遍”,按次数是否确定来选。
  • while 用到的变量要在进循环前初始化,否则第一次比较就报错。
  • 结束循环的方式有四种:条件变假、标志变量、break、return(函数里),复杂场景优先用标志。
  • continue 跳过本次剩余代码,注意别把让条件变化的语句也跳过去。
  • 循环的 else 在正常结束时执行,被 break 打断时不执行,适合”查找没找到”的场景。
