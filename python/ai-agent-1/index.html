引言

其实直白的说,Agent也就是一个管理并且辅助AI模型的程序,其实原理很简单,只不过需要做一个商用级别的,需要的要求肯定很多,这就是另一个难度了

简介

摘自维基百科
Agent harness是大型语言模型（LLM）的软件基础架构，使大型语言模型可以发挥人工智能代理的功能。agent harness会处理工具使用、记忆、状态持久性、执行环境及回馈回路，而大型语言模型会进行理解的工作。有一个2026年开始流行的缩写，将这几个技术简化为Agent = Model + Harness。

因为LLM本身无状态，在没有其他工具的协助下，只能产生文字，harness就是让模型可以依照步骤采取行动、使用外部工具，以及在不同的对话之间持续进行长任务的关键。最原始的作法是重复地在上下文窗口中读取持续增加的文字，不过harness会在线下进行记录，使其变成结构化软件环境。若是单一提示和单一回应，不需要harness，但若任务变成有几个步骤，需考虑工具，或是要长久执行，就需要harness了。

流程概览

flowchart TD A([用户输入]) --> B["调 API（带上 tools 定义）"] B --> C["模型返回 tool_call"] C --> D["是"] D --> E["执行本地工具（读文件、跑命令）"] E --> B C --> F["否"] F --> I["输出最终回复，等下一轮"]
