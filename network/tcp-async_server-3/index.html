如何用Boost.Asio库写一个自己的服务TCP异步服务器(三)

CSession功能实现

类功能

Cession作为一个会话类,主要的作用其实就是实现和客户端的通信,所以最重要的也就是读函数和写函数,
然后在读回调函数里面把接收到的消息传入逻辑队列,交给逻辑类处理后续,也防止了内部堵塞

CSession.h

函数定义

有些函数一眼看出来功能就不说了

  1. 构造函数
    主要是初始化CSession内部的_socket和传入外部的server来管理CSession,
    然后再生成一个uuid,这玩意用于确认会话的身份,而且会话是要被放在一个定义在CServer的哈希表里面的(增加智能指针的引用),有了uuid才好管理.

  2. Start
    这个函数一句话说就是,用于会话的启动,有了第一个异步读函数,才能够启动后面的回调函数

  3. HandleWrite
    这个是写回调函数,内部实现是boost::asio::async_write,这个函数是boost库提供的异步读函数,能一次发完所有数据.这个回调函数也不只是只有这一点内容,其实还有锁和消息队列.锁的话,是为了防止入队顺序的错乱导致的数据混乱,队列就是为了让消息按顺序发送,并且提供一个缓冲区,要是不做一个队列的话,那么需要用到很多的异步回调函数来发送,性能开销就会变大.

  4. HandleRead
    这个才是重头戏,这个是整个类里面实现最为复杂的函数,首先要分段的取数据,首先提取头数据,根据bytes_transferred的是否被用光,来决定是否调用下一个回调函数,return当前的.然后要是是足够的,那就根据头数据来获取数据长度和数据id,然后再接收主数据部分,大概呢就是这么一个思想

CSession.cpp

总结

CSession类是这个项目里面最重要的类,所有要理解起来还是有点难度,下一期实现CServer类,CServer类其实就是个连接接收器和会话管理器,也是一个很重要的类.
