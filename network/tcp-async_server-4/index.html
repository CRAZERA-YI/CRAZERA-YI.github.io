如何用Boost.Asio库写一个自己的服务TCP异步服务器(四)

CServer功能实现

类功能

CServer的功能其实是作为一个管理器的,负责对端的和服务端之间的通信管理,也是一个很重要的类

CSession.h

函数定义

这个类的函数也就两个很重要

  1. StartAccept
    这个函数用于生成CSession和启动对监听到的socket的接收,然后调用回调函数
  2. HandleAccept
    作为回调函数,在异步通信里面是很重要的东西.这个函数的功能是,利用CSession,把接收到的socket启动通信,并且开始下一轮的监听接收

CSession.cpp

代码实现其实也很简单

总结

CServer提供了对于会话的管理,让服务器的运作有条理起来了,而且也降低了耦合度,下一期讲实现Singleton,为逻辑类做准备
