图片贴合地图的实现

引言

起因是因为需要解决一个项目上的技术问题,对于我的能力来说,解决不了,所以只要请问GPT了,下面是GPT给出的算法,我尽力以我的语言来把这个原理讲清楚,以供学习.

问题

对于这个项目来说,我们需要做到把图片铺到地图上的对应位置上去,还需要保证图片不是真和转弯处过度平滑,并且跳转到对应的地点的地图方位

解决思路

首先有几个技术要点需要说明:

  • 如何确定图片要放置的位置
    答 : 先用csv文件模拟图片对应的经纬度
  • 如何实现转弯
    答 : 切分再补点
  • 如何如何确认道路宽度
    答 : 目前先手动调节,后续的数据文件中会附带有

算法的思路:

前置准备 :

图片：一张带条纹的长方形图
路线：你 .csv文件中的一系列坐标点
宽度：n米(不重要,只是一个演示而已,具体数据以实际情况为准)

处理坐标

  1. 预处理,将坐标组加载到vector中
  2. vector中的坐标为经纬度坐标,需要转化为墨卡托坐标(即平面坐标系坐标)
  3. 得到转化后的坐标,存到另一个容器里面备用
  4. 现在的这些点是离散的,我们需要对他们进行一些处理,使得路径顺滑转弯
  5. 再准备一个容器来储存补点后的路径(顺滑路径)
  6. 用一个函数来补点,然后存入容器,现在这个路线就是一个比较平滑的路线了

关联路径和图片

此时,就该把图片和路径对应起来了

  1. 首先,我们先算出这个路径的路程有多长,用一个专门的结构体来保存这个数据,用于后续图片对应
  2. 然后开始括宽,把点集变成有宽度的值,其实就是给每个点加两个路面边界坐标,然后就可以开始铺图了

铺图

原图横坐标 = 已走距离/道路总长*原图最大横坐标

  1. 确认尺寸,创建一个透明的画布对象
  2. 两个”线段数据”确定一个四边形
  3. 四边形对应图片位置
  4. 然后把四边形分为两个三角形,给目标画布对象的对应位置填色
  5. 一此类推,获得目标图层的图片

放置到地图对应位置上方

  1. 把画布对象的xy坐标换算为经纬度坐标
  2. 画布对象也保存为png文件(png才支持透明背景)
  3. 放到地图上对应的经纬度位置
