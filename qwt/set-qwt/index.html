Qwt环境配置教程

VS2022配置 Qwt 6.3.0 全流程

引言

本文记录在 Windows 64 位环境下，使用 Visual Studio 2022 配合 Qt 5.12.12 配置 Qwt 6.3.0

0. 前置准备

组件 版本 / 说明 示例路径（按本机实际路径调整）
Visual Studio Visual Studio 2022 Community本电脑使用的vs版本 D:\Visual Studio\Visual Studio 2022\Community
Qt 套件 Qt 5.12.12 本电脑qt版本 D:\Qt\Qt5.12.12\5.12.12\msvc2017_64
多线程构建器 Qt Creator 自带 jom.exe（或 VS 自带 nmake.exe） D:\Qt\Qt5.12.12\Tools\QtCreator\bin\jom\jom.exe

1. 下载并配置 Qwt 6.3.0 源码

  1. 从 SourceForge 官方发布页下载源码包 qwt-6.3.0.zip：
    • 下载地址：https://sourceforge.net/projects/qwt/files/qwt/6.3.0/qwt-6.3.0.zip/download
  2. 解压到一个无中文、无空格的临时构建目录，例如：D:\Qt\_qwt_build\qwt-6.3.0。
  3. 用文本编辑器打开源码根目录下的 qwtconfig.pri，做两处修改：

3. 配置vs2022项目

如果想逐项了解底层配置项，可以在 项目属性（平台选 x64） 中手动填写：

属性页位置 Debug|x64 填写值 Release|x64 填写值
C/C++ → 常规 → 附加包含目录 D:\Qt\Qwt-6.3.0\include(请填写自己电脑里面对应的路径) D:\Qt\Qwt-6.3.0\include
C/C++ → 预处理器 → 预处理器定义 _SILENCE_STDEXT_ARR_ITERS_DEPRECATION_WARNING _SILENCE_STDEXT_ARR_ITERS_DEPRECATION_WARNING
链接器 → 常规 → 附加库目录 D:\Qt\Qwt-6.3.0\lib(请填写自己电脑里面对应的路径) D:\Qt\Qwt-6.3.0\lib
链接器 → 输入 → 附加依赖项 qwtd.lib qwt.lib
